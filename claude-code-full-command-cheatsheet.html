01第一次进项目

cd 项目目录
claude
/init → /memory → /permissions

生成 CLAUDE.md，补充项目规则，再设置工具权限。

02大改动别莽

/plan 先让它列方案
/diff 看改了什么
/code-review --fix

先规划、再执行、最后复核，最稳。

03上下文爆了

/context 看占用
/compact 压缩总结
/clear 开新任务

长任务优先 compact，不要一直硬聊。

04出问题先查

/status 查版本/账号/连接
/doctor 自动诊断
/debug 看日志排错

不要一上来重装，先定位。

外部 CLI 启动命令

claude
打开交互式 Claude Code。
claude "问题"
带一个初始问题启动。
claude -p "问题"
非交互执行，输出后退出，适合脚本。
cat log.txt | claude -p "分析"
把文件/日志管道给 Claude 处理。
claude -c
继续当前目录最近一次会话。
claude -r "会话名"
恢复指定会话。
claude update
更新 Claude Code。
claude install stable
安装/重装稳定版。
claude auth login
登录 Anthropic / Claude 账号。
claude auth status
检查登录状态，排错第一步。
claude agents
查看/管理后台 agent 会话。
claude mcp
配置 MCP 服务。

高频参数 / 快捷键

--model
指定模型，如 --model sonnet。
--effort high
提高推理强度；大任务更适合。
--add-dir ../x
额外授权可读写目录。
--debug
打开调试日志。
--mcp-config
加载 MCP 配置文件。
--output-format json
脚本化输出 JSON。
Ctrl+C
中断 / 清空输入 / 退出。
Ctrl+R
搜索历史命令。
Shift+Tab
切换权限模式：默认、计划、自动等。
Esc Esc
清空输入或打开回滚菜单。
危险提醒：--dangerously-skip-permissions 只适合非常确定的沙盒环境。新手资料里建议只讲“不推荐乱开”，不要把它包装成懒人技巧。

复制区：直接贴给 Claude Code 的提示词

这些不是系统命令，但比命令更像“工作流开关”。

先不要修改文件，先阅读项目结构、列出风险点和执行计划。
先解释你要改哪些文件、为什么改、可能影响哪里，等我确认。
按最小改动原则修复，不要顺手重构无关代码。
每次改完请运行项目现有测试/构建命令，并说明结果。
如果需要删除/覆盖/迁移文件，必须先暂停并征求确认。
请把本项目长期规则整理进 CLAUDE.md，但不要覆盖我已有内容。

环境变量 / 配置速记

位置作用
~/.claude/settings.json只对你个人、所有项目生效。
.claude/settings.json项目级配置，可随仓库共享。
.claude/settings.local.json本项目个人配置，不建议提交。
ANTHROPIC_API_KEYAPI Key 鉴权；设置后可能覆盖订阅登录。
ANTHROPIC_BASE_URL代理/网关转发地址；排错时要确认是否被错误设置。
API_TIMEOUT_MS请求超时时间。

命令使用纪律

先 /status再 /doctor必要时 /debug大改先 /plan改后看 /diff提交前 /code-review上线前 /verify长聊用 /compact新任务用 /clear危险权限少开
