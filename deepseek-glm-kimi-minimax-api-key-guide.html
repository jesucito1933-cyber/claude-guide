国产大模型 API Key 获取方法一页速查表

适合放进 AI 上手包 / 社群资料 / 公众号赠品：把四家平台的入口、创建步骤、Base URL、环境变量和常见坑放在一页里，用户照着抄就能接入。

整理日期：2026-06-08｜平台入口、模型名、计费规则会更新；实际以各平台官网控制台与官方文档为准。API Key 属于敏感信息，不要截图外发、不要写进公开仓库。

01先注册/登录

进入对应开放平台
完成手机号/邮箱/实名/组织信息

国内平台经常需要手机号，部分能力可能需要充值或开通权限。

02创建 API Key

控制台 → API Keys
Create / 创建密钥
复制并保存，只显示一次

不要把 Key 直接贴到前端代码、截图、GitHub、微信群。

03配置环境变量

export XXX_API_KEY="你的key"
base_url 选对地区/协议

OpenAI 兼容、Anthropic 兼容的 Base URL 不一定一样。

04先跑最小测试

curl / Python SDK
401 查 Key，402/余额查计费
404 查模型名和地址

别一上来接 Claude Code / Cursor，先确认 API 本身能通。

DeepSeek

1访问 DeepSeek Platform，登录账号。
2进入 API Keys 页面，点击创建 Key。
3复制保存 Key；调用时使用 Bearer Auth。
4如果无法调用，优先检查余额、限流、Base URL、模型名。
Key 页面
platform.deepseek.com/api_keys
OpenAI URL
https://api.deepseek.com
Anthropic URL
https://api.deepseek.com/anthropic
环境变量
DEEPSEEK_API_KEY
模型示例
deepseek-v4-pro / deepseek-v4-flash
注意：官方文档显示旧模型名 deepseek-chat、deepseek-reasoner 将在 2026-07-24 后弃用，做教程时建议用新模型名。

GLM / 智谱

1访问智谱开放平台 open.bigmodel.cn。
2注册/登录后，进入个人中心。
3点击 API Keys，创建新的 API Key。
4选择模型和开发方式：HTTP API / Python SDK / Java SDK。
入口
open.bigmodel.cn
通用 URL
https://open.bigmodel.cn/api/paas/v4
Coding URL
https://open.bigmodel.cn/api/coding/paas/v4
认证
Authorization: Bearer YOUR_API_KEY
模型示例
glm-5.1 / GLM-5V-Turbo / GLM-Image
注意：如果你买的是 GLM 编码套餐，官方提醒要用 Coding 端点，不要误用通用端点。

Kimi / Moonshot

1访问 Kimi 开放平台 / Moonshot 控制台。
2进入 开发工作台 或 API Keys。
3创建 API Key，默认项目一般选 default。
4确认余额充足，再接入 OpenAI SDK 兼容格式。
Key 页面
platform.kimi.com/console/api-keys 或 platform.moonshot.cn/console/api-keys
国内 URL
https://api.moonshot.cn/v1
国际 URL
https://api.moonshot.ai/v1
环境变量
MOONSHOT_API_KEY
模型示例
kimi-k2.6 / kimi-k2.5 / kimi-for-coding
注意：Kimi 聊天网页账号、Kimi For Coding 权益、Moonshot 开放平台 Key 可能不是同一套配置，接工具时要看清 Provider。

MiniMax

1按地区访问 MiniMax API Platform：国际站或国内站。
2注册/登录后，进入 API Keys。
3Pay-as-you-go 选择 Create new secret key。
4Token Plan 用户去 Billing → Token Plan 查看 Subscription Key。
国际站
platform.minimax.io
国内站
platform.minimaxi.com
OpenAI URL
国际：api.minimax.io/v1｜国内：api.minimaxi.com/v1
Anthropic URL
国际：api.minimax.io/anthropic｜国内：api.minimaxi.com/anthropic
模型示例
MiniMax-M3 / MiniMax-M2.7 / MiniMax-M2
注意：MiniMax 官方把 Pay-as-you-go API Key 和 Token Plan Subscription Key 分开说明，别填错。

复制区：环境变量 + 最小测试

DeepSeek
export DEEPSEEK_API_KEY="你的 DeepSeek Key"
curl https://api.deepseek.com/chat/completions \
-H "Content-Type: application/json" \
-H "Authorization: Bearer $DEEPSEEK_API_KEY" \
-d '{"model":"deepseek-v4-pro","messages":[{"role":"user","content":"hello"}]}'
GLM
export ZHIPUAI_API_KEY="你的智谱 Key"
curl https://open.bigmodel.cn/api/paas/v4/chat/completions \
-H "Content-Type: application/json" \
-H "Authorization: Bearer $ZHIPUAI_API_KEY" \
-d '{"model":"glm-5.1","messages":[{"role":"user","content":"你好"}]}'
Kimi
export MOONSHOT_API_KEY="你的 Kimi / Moonshot Key"
curl https://api.moonshot.cn/v1/chat/completions \
-H "Content-Type: application/json" \
-H "Authorization: Bearer $MOONSHOT_API_KEY" \
-d '{"model":"kimi-k2.6","messages":[{"role":"user","content":"你好"}]}'
MiniMax
export MINIMAX_API_KEY="你的 MiniMax Key"
curl https://api.minimax.io/v1/text/chatcompletion_v2 \
-H "Content-Type: application/json" \
-H "Authorization: Bearer $MINIMAX_API_KEY" \
-d '{"model":"MiniMax-M3","messages":[{"role":"user","content":"hello"}]}'
国内用户把域名换成 api.minimaxi.com；如果使用 Anthropic 兼容接 Claude Code，则使用 /anthropic Base URL。

接入工具时最容易踩的坑

问题优先排查解决动作
401 / UnauthorizedKey 错、环境变量没生效、复制多了空格重新生成 Key；终端执行 echo $XXX_API_KEY 检查。
402 / 余额不足余额、套餐、Token Plan 权益去 Billing / Balance / Token Plan 页面确认。
404 / model not found模型名写错、旧模型弃用、地区站不一致复制官方模型名；先用官方示例跑通。
请求超时网络、代理、Base URL、地区国内/国际站域名别混；先 curl 测试。
Claude Code 接不上OpenAI 兼容和 Anthropic 兼容 URL 混用Claude Code 类工具优先看是否需要 Anthropic 兼容地址。
Cursor / Cline 无响应Provider、Base URL、模型名、余额先在控制台或 curl 跑通，再接工具。

Key 管理纪律

不要写前端不要提交 Git不要截图外发不要放公众号源码用 .env分项目建 Key泄露立刻删除定期轮换设置额度预警教程只放占位符
社群资料建议写法：永远用 YOUR_API_KEY、<MINIMAX_API_KEY> 这类占位符，不要为了演示方便放真实 Key。哪怕余额只有几块钱，也会被爬虫扫空。
